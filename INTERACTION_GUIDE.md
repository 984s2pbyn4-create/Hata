# Интерактивные механизмы · DARK TECH FAMILY FINAL v8

## Порядок работы

Откройте `tour.html` на GitHub Pages или локальном HTTP-сервере. В правой панели выберите любую из трёх палитр и жизненный этап. Кнопки «Семейный вечер», «Ночёвка гостя», «Готовка», «Ноутбук», «Кино» и «Двое школьников» переключают несколько параметров одновременно.

Для точечного действия используйте отдельные кнопки: **диван-кровать, столешница, ноутбук-панель, экран проектора, секция гардеробной**. Модель вращается мышью или пальцем, увеличивается прокруткой/щипком. Есть кнопки вида сверху, по комнатам, сравнения двух вариантов рядом, среза стен и сохранения PNG.

## Сценарии

| Действие | Технический эффект | Примечание |
|---|---|---|
| Разложить диван | Загрузка объёмной конфигурации `guest` | Дополнительная столешница убирается |
| Выдвинуть полуостров | Горизонтальный сдвиг 3D-поверхности примерно на 0,68 м | Только в обычном режиме |
| Открыть ноутбук | Поворот откидного элемента на 90° | Не использовать для опасной пайки при детях |
| Опустить экран | Трансформация полотна проектора | Это демонстрация механики и света, не расчёт экрана |
| Открыть гардероб | Перемещение мебельного фасада | Два существующих входа не затрагиваются |
| Кино | Вечернее освещение + экран | Полное затемнение требует физических штор |
| Двое малышей | Две низкие кровати | Без верхнего спального места |
| Школьники | Блок кроватей и рабочих мест | Только после проверки роста детей и высоты потолка |

**Эти действия описывают геометрию и сценарии, но не заменяют механику мебельного конструктора.** В GLB сохранено исходное положение подвижных панелей; движение выполняет встроенный браузерный скрипт. Разложенное состояние дивана представлено отдельной GLB-конфигурацией.

## Быстрые ссылки

- `tour.html?scene=guest` — гостевой сон.
- `tour.html?scene=cooking` — большая рабочая поверхность.
- `tour.html?scene=work` — зона ноутбука.
- `tour.html?scene=movie` — кино.
- `tour.html?scene=school` — два будущих школьных места.
- `tour.html?style=graphite&view=living` — родительская спальня в тёмной палитре.
- `tour.html?style=japandi&view=closet` — гардеробная в оливковой палитре.
- `rooms.html?room=bedroom&style=warm` — альбом детской.

Верхнее спальное место, мокрая техзона, смоляной принтер, звукоизоляция и выводы вентиляции требуют отдельных проверок, которых эта концептуальная модель не выполняет.
