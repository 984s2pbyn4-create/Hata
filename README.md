# DARK TECH FAMILY · FINAL v8

**Финальный комплект концептуального дизайн-проекта и интерактивного 3D-прототипа для GitHub Pages.**

Проект основан на двух предоставленных изображениях планировки и семиэтапном интервью. Поддерживает три варианта отделки внутри согласованного стиля DARK TECH, 3 возрастные конфигурации детской, 3 состояния кухни-гостиной и подвижную мебель. **Не является рабочей строительной документацией.**

## Запуск

**На GitHub Pages:** распакуйте ZIP, перенесите **содержимое** папки в корень репозитория, затем `Settings → Pages → Deploy from a branch → main → / (root)`. Откройте опубликованную ссылку. Никакой npm-сборки и внешних CDN не требуется.

**Локально:** из распакованной папки выполните `python -m http.server 8000` и откройте `http://localhost:8000`. Для `tour.html` открытие двойным кликом через `file://` не рекомендуется: браузер может блокировать загрузку GLB через `fetch`.

## 3D-интерактив

- Сложить/разложить диван-кровать для ночующего гостя.
- Выдвинуть/убрать дополнительную кухонную столешницу.
- Открыть/закрыть откидную ноутбук-консоль.
- Опустить/поднять проекционный экран.
- Сдвинуть фасад секции хранения в гардеробной **без перекрытия двух входов**.
- Включить кинотеатр (вечерний свет и экран), день/закат/вечер.
- Переключить детскую: сейчас → два малыша → школьный возраст.
- Переключить кухню: повседневная жизнь → гость ночует → ужин на шестерых.
- Сравнить два стиля рядом, открыть любую комнату или пустую планировку, сохранить PNG, скачать GLB.

Некоторые действия намеренно несовместимы: например, диван-кровать убирает выдвижную столешницу. Движения панелей выполняются в браузере; отдельные GLB содержат их **начальные** положения. Подробности в `INTERACTION_GUIDE.md`.

## Состав

- `models/` — 27 меблированных GLB (3 палитры × 3 возраста × 3 режима кухни) и отдельная модель-планировка.
- `assets/model_views/` — 27 контрольных ракурсов, полученных из моделей, и 6 кадров интерактивных сценариев.
- `assets/concept/` — фотореалистичные **атмосферные концепты**, не являющиеся точными рендерами обмерной геометрии.
- `plans/` — PNG и SVG-схемы, в том числе спальня с двумя входами в гардеробную.
- `data/furniture_equipment_schedule.csv` — ведомость мебели, техники и оборудования без стоимости (бюджет исключён по запросу).
- `source/` — исходная геометрия в JSON и Python-скрипты предыдущих этапов.
- `data/FINAL_QA.json` — результаты автоматизированной проверки.
- `FINAL_HANDOVER.md` — паспорт финальной передачи и перечень ограничений.

## Точность и безопасность

**Подтверждено собственником:** гардеробная у родительской спальни, два отдельных входа (из спальни и коридора); детская в комнате 12,2 м²; спальня родителей 13,8 м²; кухня 15,4 м². **Не подтверждено обмерами:** точная высота потолков (в модели временно 2,72 м), размеры и координаты некоторых проёмов, точные коммуникации. Модель не содержит разрешения на изменения несущих панелей.

Фотореалистичные концепты — ориентир по стилю, технические 3D-ракурсы — ориентир по геометрии принятой модели. Фотореалистичных рендеров **строго из той же низкополигональной геометрии** в комплекте нет; не использовать концепты для снятия размеров.

Механизмы, крепления, нагрузки, узлы электрики, вентиляцию, звукоизоляцию, устройство тёплых полов, слив душа и размещение оборудования на лоджии необходимо проектировать и проверять до ремонта. **Фотополимерная печать на лоджии не утверждена к размещению** без обособленного безопасного решения.
